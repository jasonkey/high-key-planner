# src/

Source for the web tool. `assemble.py` concatenates these into `site/index.html`.

```bash
python assemble.py           # rebuild site/index.html
```

| file | what it is |
|---|---|
| `web/head.html` | `<title>` and all CSS, including the print rules |
| `web/body.html` | page markup |
| `web/app.js` | Aspen parsing, schedule resolution |
| `web/ui.js` | the three steps, the weekly page renderer |
| `web/xlsx.js` | spreadsheet export |
| `district_data.json` | the 2026/27 calendar, generated by `gen_district_data.py` |

`gen_district_data.py` reads `workbooks/planner.py` and writes `district_data.json`,
so the web tool and the workbook generator can never drift apart.
